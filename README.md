# Belka Travel Concierge - Interactive 3-Language Slideshow

## Files Included

1. **slideshow.html** - Main interactive presentation (open in any web browser)
2. **Belka_Travel_Concierge_AR.pdf** - Full Arabic translation (16 pages)
3. **pg_ru_01.png to pg_ru_16.png** - Russian language page images (16 pages)
4. **pg_ar_01.png to pg_ar_16.png** - Arabic language page images (16 pages)

## How to Use

### Opening the Slideshow
Simply open **slideshow.html** in any modern web browser (Chrome, Firefox, Safari, Edge, etc.)

### Language Selection
- Click **RU** for Russian (Русский)
- Click **AR** for Arabic (العربية)
- Click **EN** for English

### Navigation
- **NEXT** / **PREV** buttons to manually navigate
- **Arrow keys** (← →) for keyboard navigation
- **Click language buttons** to switch between Russian, Arabic, and English
- **Space bar** to play/pause auto-advance

### Auto-Play Features
- **Default:** Automatically advances every 30 seconds
- **PAUSE button:** Stops automatic advancement
- **Progress bar:** Shows time remaining before next slide
- **Timer display:** Countdown in seconds (e.g., "30s", "15s", "0s")

### Display Information
- **Page counter:** Top-left shows current page (e.g., "1 / 16")
- **Page info:** Bottom shows "Page X of 16"

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `→` | Next slide |
| `←` | Previous slide |

## Tips

1. **Fullscreen Mode:** Press F11 in browser for fullscreen presentation
2. **Best Quality:** Images are optimized at 1.2x resolution for crisp display
3. **Mobile Friendly:** Buttons are touch-responsive; use device in landscape mode
4. **Pausing:** Pause the auto-advance to study individual slides in depth
5. **Language Switching:** Switch languages at any time without resetting to first slide

## Troubleshooting

**Images not loading?**
- Ensure all `pg_*.png` files are in the same folder as `slideshow.html`
- Check browser console (F12) for error messages
- Try refreshing the page (Ctrl+R or Cmd+R)

**Auto-advance not working?**
- Check if PAUSE button shows "▶ PLAY" (click to resume)
- Verify browser allows JavaScript execution
- Try a different browser

**Text too small on mobile?**
- Use landscape orientation for better display
- Pinch-zoom to adjust size (most browsers support this)
